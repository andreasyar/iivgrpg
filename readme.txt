Развёртывание сервера и клиента для разработки.

Что нужно для клиента:
    - браузер FireFox 11+, Chrome 15+ или любой другой, который поддерживает
      WebSocket последней версии (RFC 6455),
    - среда разработки на ваш вкус (на мой вкус: NetBeans с плагином PHP), если
      на мой вкус, то можно просто создать PHP проект с существующими
      исходниками и не беда, что в клиенте нет ни одного .php файла.
    - в директории client в своей рабочей копии нужно создать директорию cache
      и поместить в неё файлы из архива cache-25-05-2012.zip иначе клиент не
      запустится. А так же распаковать спрайты из архива Images-r72.zip в
      директорию client Архивы можно скачать в разделе Downloads:
      http://code.google.com/p/iivgprg/downloads/list

Что нужно для сервера:
    - установленный и запущенный MySQL сервер, параметры доступа которого надо
      прописать в конфиг. Конфиг создаётся копированием файла
      trunk/server/config.xml в файл с именем config-home.xml Потому что
      config.xml - это как бы шаблон конфига, который лежит в репозитории, а
      у каждого конкретного пользователя или разработчика вообще говоря свой
      конфиг и он зовётся config-home.xml
    - на mysql сервере надо создать базу данных iivgrpg командой create
      database iivgrpg; из консоли mysql например.
    - опять же среда разработки на ваш вкус (на мой вкус: NetBeans).

Теперь можно запустить сервер, например выполнив файл ServerLauncher.java из
среды разработки не взирая на ошибки. И попытаться соединиться с ним из
клиента. Если всё ок, то клиент напишет что-нибудь без красненького в консоли
браузера (вызывается по нажатию F12).

----------------------------------------------------------
Старое развёртывание:

-Развёртывание
1. Распаковать архив с картинками (http://code.google.com/p/iivgprg/downloads/list) в папку клиента
2. Иметь mysql сервер
3. Иметь в mysql дамп бд (server/dump.sql)
4. Скопировать server/loc.server.xml в server/server.xml и настроить под себя
5. Создать в client/ папку cache
