# Перенос архивов в Git

Перенос выполнен 3 ноября 2026 года из локального комплекта `iivgrpg-legacy`.
Исходный комплект не изменялся. Полный дамп находится только в исходном архиве:
`google-code/repository.svndump.gz`; в Git он не добавляется, поскольку содержит
исключённые материалы. Исходный адрес проекта: `http://iivgprg.googlecode.com/svn`.

## Основная история

- `main`: r1–r129, строго по одному коммиту на ревизию, включая пустые после
  фильтрации. Пустые каталоги `branches/` и `tags/` не представлены: Git не хранит
  пустые каталоги. Настоящих SVN-веток или тегов в дампе нет.
- Содержимое `trunk/` помещено в корень, wiki сохранена в `wiki/`.
- Сохранены исходные сообщения, включая пустые; служебные подписи в них не добавлены.
- Author и committer соответствуют SVN-автору; для r1 автор отсутствует,
  использован `google:author=unknown` и технический адрес `unknown@authors.invalid`.
- Git хранит даты с точностью до секунды. Исходные микросекунды, полные revprops
  и соответствие ревизий Git-коммитам находятся в `import-report.json`.
  Часовой пояс Git — UTC; сохранён исходный момент времени.
- История свойств узлов (например, `svn:ignore`) сохранена отдельно в
  `svn-node-properties.json`. В дампе нет свойств executable или special.
- Файлы сохранялись побайтно, без нормализации переводов строк. CRLF/LF
  нормализовались только для поиска дублей локальных копий.
- Последний коммит `main` добавляет документацию, скрипты переноса и `.gitignore`.
  Он не изменяет исторический код. Теги SVN-ревизий не созданы.

## Локальные дополнения

Проверены все 11 деревьев из `preserved-source-trees.json`, обычные файлы,
конфликтные `.mine`/`.rNN`, а также исторические исходники в SVN text-base и
NetBeans base. Каждая дополнительная версия сравнивалась со **всеми** ревизиями,
а не только с последней. Повторяющиеся копии не создают новых веток.

| Независимая ветка | Файлов дополнений | Содержание |
| --- | ---: | --- |
| `historical/local-r129` | 6 | Поздний кэш карт и настройки клиента NetBeans |
| `historical/netbeans-server` | 11 | Ранняя Ant/NetBeans-сборка сервера, конфигурация и вариант кэша `cahce` |
| `historical/map-events` | 6 | События клеток, переход на другую карту, заметки разработчика и варианты кэша |
| `historical/netbeans-server-later` | 6 | Другой вариант сборки NetBeans и конфигурации сервера |
| `historical/client-conflicts` | 12 | Незавершённые SVN-конфликты, две уникальные `.mine`-версии, настройки и кэш |

Каждая ветка — orphan с одним коммитом и только отличиями; общий исходный код
в неё не копировался. `HISTORICAL-SNAPSHOT.json` перечисляет исходные пути,
SHA-256 и время изменения файлов. Повторные дополнительные версии с тем же
логическим путём и содержимым указывают на уже созданную ветку в общем отчёте.
Поле ближайшей SVN-ревизии — оценка по совпадающим файлам смешанной рабочей
копии, а не доказанная точка ответвления; при отсутствии исходников для сравнения
там `null`. Реальные автор и дата незакоммиченных правок неизвестны, поэтому
коммиты этих веток честно датированы переносом и имеют технического автора.
Оригинальные времена файлов сохранены только как сведения о происхождении.

`client-conflicts` оставлена как материал для извлечения старых наработок:
маркеры конфликтов сохранены, эта ветка не считается рабочей сборкой.
Для просмотра дополнений используйте `git show historical/map-events:client/Player.js`;
для сравнения с основной историей — хеш соответствующей ревизии из отчёта.
Целиком сливать неполные orphan-ветки в `main` не следует: нужные файлы переносятся отдельно.

## Исключения

Из всех ревизий SVN удалены четыре файла игровой графики:
`client/mmorts/grass.png`, `client/mmorts/peasant.png`,
`client/mmorts/peasant_selected.png`, `server/webapp/imgs/4_0.png`,
а также `server/dump.sql`. Локальные спрайты, скриншот с игровой графикой,
архивы ресурсов и дампы тоже не импортировались.
Изображения диаграмм в сторонней документации Netty сохранены: это не игровые
спрайты. Сторонние библиотеки, их исходники и лицензии из SVN сохранены.

Из локальных дополнений не переносились повторные результаты сборки
(`build/`, `dist/`, `.class`), приватные пользовательские настройки IDE,
нулевые файлы-заглушки и служебные SVN-каталоги. Ненулевые исходники из
`text-base` и `.netbeans-base` проверены: дополнительных версий вне SVN нет.
Обнаруженная в локальном `server/.project` настройка
`__CREATED_BY_JAVA_LANGUAGE_SERVER__` относится к современной IDE и не включена
в исторические ветки. Причина решения по каждому обычному файлу есть в отчёте.

Метаданные Google Code указывают BSD, но отдельная лицензия для всего проекта
при переносе не сочинялась. Сохранены существовавшие тексты лицензий зависимостей.

## Воспроизведение и проверки

Нужны Python 3 и Git. Пакеты SVN и сеть не требуются. Путь исходного архива задан
в `inspect_dump.py`; при другом расположении измените `ROOT`.

```sh
python3 migration/import_history.py /tmp/iivgrpg-rebuilt
python3 migration/verify.py /tmp/iivgrpg-rebuilt
```

Целевая директория должна быть пустой. Импортёр восстанавливает SVN и orphan-ветки,
пишет отчёт и скрипты. README, `.gitignore` и завершающий коммит документации
добавляются отдельно. Коммиты переноса используют текущее время; исторические
SVN-коммиты воспроизводятся с теми же хешами.

Проверка сверяет деревья всех 129 коммитов, их родителей, авторов, даты и сообщения
с дампом; проверяет MD5/SHA-1 полных текстов при разборе, последний снимок с
независимой выгрузкой Google Code, происхождение файлов всех orphan-веток,
все дополнительные исходники SVN/NetBeans и все Git-blobs на дампы БД.
Проверяет также отсутствие исключённых blobs по хешам, содержимое JAR на
упакованные дампы и известные спрайты, отсутствие SVN-тегов и `git fsck --full --strict`.
Результат последней проверки — `verification.json`.

Удалённый GitHub-репозиторий не настроен, push не выполнялся. Для будущей публикации
необходимо отправить `main` **и** `historical/*` (например, `git push origin --all`).
